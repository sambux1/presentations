# Oblivious Shuffling

<br>

Two parties, $P_0$ and $P_1$, want to shuffle a secret-shared vector $[\mathbf{x}]$ by a permutation $\pi$.

<v-clicks>

- Neither party should learn anything about $\pi$
- The output is a secret sharing $[\pi(\mathbf{x})]$

</v-clicks>
